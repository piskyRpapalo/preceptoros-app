# PreceptorOS APP · first use for four Android collaborators

**Who owns it:** Each person owns their Companion, data, models, Lab and device. PreceptorOS provides tools and communication, not control over their devices.

## Three steps to perform in the APP

**1 — Discover PreceptorOS.** Open Talk and read the three-step introduction. You can explore the six panels without creating an account. Open World is a public area, but publishing your Companion is a separate, reviewed action.

**2 — Meet your Mini Orchestrator.** Press **Find local Mini Orchestrator**. It opens the existing model chooser without activating anything. On the browser/offline fallback, press **Use Mini Orchestrator offline** yourself; its help, navigation and routing are deterministic. A model-generated reply requires a verified Android inference runtime. Never assume the presence of a button or GGUF proves quality or connectivity.

**3 — Configure your node.** Press **Open Node identity**. Edit the Companion name and a short description; accept or edit the neutral prompt. Press **Keep these defaults on this device** to save the draft locally. **Suggest my node ID** fills the ID field but does not save, register, guarantee uniqueness or request admission. Follow the existing consent controls for actual identity storage and review. No account, SSH, API key or model is required to create this draft.

**Lab without programming.** Open Lab and choose **Write my first experiment plan**. This opens the existing Operations Data plan editor; describe a goal and expected result, then decide yourself whether to store it. Opening Lab or the plan editor never runs a job.

**Joining Open World.** In My node → Node identity choose **Prepare admission request**. A draft is not a deployed node. A human approval, signed credential and authenticated heartbeat are separate requirements before LIVE. The existing Android→Aduana client and public installation path must be verified before implying they work.

## Privacy and accessibility

- Drafts stay in the browser's **unencrypted** local storage unless explicitly exported or used elsewhere. Do not type secrets or another person's private data.
- Speech/tones need opt-in. Settings contains speech Stop, text size, contrast and reduced motion.
- Keyboard and screen-reader labels remain when the Agents indicator is red; red signifies **no verified active agent**, not proof that an agent failed.
- The crab greeting is visual only; it does not prove inference is running.
- An unconfigured model, a disconnected endpoint and a pending node are **not** LIVE.

**Meeting quick test:** each of the four collaborators can open the APP, read the guide, focus the offline Mini chooser, save a local non-secret draft, reopen it and write a plan without unexpected network POST. Test installation, offline after restart, actual Mini model inference and node admission separately on the physical Android device.

**Evidence boundary:** browser checks are not a substitute for physical Android install, TalkBack, native model quality or verified Open World registration. Record failures as NO_DATA(cause) and do not fake a green status.
