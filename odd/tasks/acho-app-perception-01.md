## Implement
Use PreceptorAudioAccessibility.controls.ids(), .read(id), .focused() locally. The bounded one-control frame uses preceptoros.acho/1, named ink/paper and one common sentence in r and tx. Explicit Alt+Shift+R on a focused catalogue control projects the same sentence to a persistent header status and, only if opted in, the existing speech mechanism; existing Read current area is unchanged. No action interface, fetch, prompt, form value, arbitrary selector or private dynamic label is exported. Availability is DOM observation, not a service or effective grant. Authorization is always NOT_GRANTED_BY_READ; only a few audited effect gates have mapped requirements, others are NO_DATA. The baseline name is a static label; current name is null when it differs or cannot be verified. This is not an AX-tree implementation.
