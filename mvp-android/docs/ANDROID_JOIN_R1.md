# PreceptorOS APP · Android deployment review bridge · R1
2026-11-19 · Codex GPT-6 · Source-only isolated branch. Not merged, installed, published or connected to production.

**Product:** PreceptorOS APP. **Included local component:** Mini Orchestrator (deterministic fallback + optional SmolLM2-135M Q4_K_M GGUF). **Private installation:** Hexelion is a separate model selected by the owner and never bundled in the public APP.

**Route from existing source, do not duplicate:** Aduana `POST https://api.preceptoros.org/api/v1/deployment-requests`, source in `brain-aduana-main-release-20261118@e22f440`, `src/deployment_intake.js`. The server accepts exactly `schema,node,device_sha256,nonce,consent:true`, <=1024 bytes; it returns an untrusted claimant receipt `AWAITING_HUMAN` (202 new / 200 replay), never an admission or LIVE witness. In November 2026 the route is not confirmed deployed publicly and GET returns 404.

**Android implementation:** Native listener via `WebViewCompat.addWebMessageListener` limited to `https://preceptoros.mvp.local`, with main-frame and URL checks; not exposed through `addJavascriptInterface`. The UI's existing `node_registration.js` expects `PreceptorAndroidJoin.requestPreliminary({node,purpose,consent})`, provided by `mvp-android/android_join_bridge.js`. JS + Android each require affirmative user consent. Android displays a native confirmation before network. The native POST is HTTPS-only to one hardcoded host, rejects redirects; 6/7-second connect/read timeouts; 1024-byte request/3072-byte response bound; validates schema, digest-bound request ID, state, timestamp, and no authority/credential/live flag. Stores random installation seed and one pending body for idempotent retry in app-private SharedPreferences. No keys, credentials, tool grants, callback URL or rack info go in request. Purpose is local-only because server contract does not allow it; this is a documented user-experience gap and requires BRAIN API approval to resolve.

**Build:** This BRANCH adds Android INTERNET permission for the explicitly consented review feature; v4 APK had intentionally no INTERNET. Cleartext HTTP is disabled. Original pinned SmolLM2 GGUF and native lib can be explicitly included in local ignored build assets; never commit binaries or secrets. The test APK vCode5 uses debug signing, not the owner's release key. No real phone or production POST was used.

**Test gates:** 18 Java pure policy checks, Node shim checks (including cross-node spoof/empty and forged LIVE), Android compileDebugJavaWithJavac, assembleDebug with model & JNI, package validation and Aduana's 14 backend intake tests x2. Public route, signed admission, recipient-side notification, heartbeat, actual World LIVE, Android physical UI, model quality/latency remain NO_DATA.
